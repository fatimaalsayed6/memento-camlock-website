Product capabilities

Purpose-built for event privacy.

01

QR-based workflow

Event QR generation supports a streamlined enrollment experience.

02

Camera availability monitoring

Uses Android camera availability callbacks to detect changes in camera availability.

03

Warning overlay

Displays a full-screen warning when a camera becomes unavailable during active event mode.

04

Cryptographic verification

Android Key Attestation is part of the security design; full verification testing is ongoing.

05

Organizer visibility · In development

Telemetry is being developed to report restriction indicators and recent device heartbeats.

06

Temporary restrictions · In development

Organizer-defined event windows are intended to govern restriction duration.

Transparent by design

The prototype does not physically disable the camera sensor or guarantee that no photo or video can be captured. Camera availability changes are indirect signals, not proof of photography. Device status reports are not independent proof of compliance.
